# РемонтКальк

Бесплатные онлайн-калькуляторы материалов для ремонта и строительства.

Сайт: [https://remontkalk.ru](https://remontkalk.ru)

## Что внутри

- 15 калькуляторов: ламинат, плитка, обои, краска, штукатурка, шпаклёвка, стяжка, наливной пол, бетон, кирпич, газоблок, гипсокартон, утеплитель и др.
- Расчёты на клиенте, без бэкенда и аккаунтов
- SEO: уникальные title/description, canonical, sitemap, JSON-LD
- Сохранение ввода в localStorage и шаринг через query-параметры

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка:

```bash
npm run typecheck
npm run test:unit
npm run build
```

## Стек

React 19, TanStack Start/Router, Tailwind v4, TypeScript.
